## 動いているもの

### 地図

- 平面 ⇄ 地球儀の切り替え（「地球」ボタン）
- 地球儀は陰影・経緯線・星空・大気光・自動回転つき。正射図法を自前で実装
- 4つの計器: 採択 / 完了 / 中止 / 配分額
- 大陸ピン・国ピン・配分額の円グラフ、すべて球面に追従
- 外部ライブラリもタイルサーバーも使わない。SVG の viewBox を動かすだけ

### 左サイドバー（三層のドリルダウン）

```
世界（国のランキング）→ 国 → 人物ランキング → プロジェクト → 詳細パネル
```

- 額は二段表示（`40M ADA` と正確な値）
- 人物は「関わったすべて」と「単独提案だけ」を併記、切り替えて並べ替えできる
- 共同提案には `※` を付ける（51% が共同提案。人物別に足すと ADA が2.0倍・USD が2.5倍になる）
- 日本語 / EN の切り替え

### 詳細パネル

- 状態フラグ（停止・不発・進行中ギャップ・過去ギャップ・遅れて完了・長期化）
- 完了報告の動画を埋め込み（587件、YouTube）
- 完了報告書へのリンク（1,761件）
- **約束と報告の対比** — 提案で約束したことと、完了報告で報告されたことを左右に並べる。判断はしない
- **質問する道具** — A と B を AI に渡す。こちらからは何も指示しない。読む人が問いを立てる。答えは保存しない。無料の Groq キーで使える

### 地図の下の欄

- **Fund の歩み** — 6年ぶんの時系列。募集→レビュー→投票→結果→着手を同じ物差しで並べ、右に予算と応募・採択数
- **約束された価値と受け取った価値** — Fund 別。F11 +30% / F14 −31%
- **事前の評価** — 中止も完了も中央値 3.67
- **数が合わない** — 公式データの不整合
- 国の一覧（97行）

## 大事な作法（守ってきたこと）

- **判断しない。** 達成・未達を決めない。良し悪しを書かない。記録を並べるだけ
- **推測で埋めない。** 「測れない」を「変化なし」にしない。役割の記録が無いなら役割を書かない
- **原文を書き換えない。** 訳は別ファイル。原文は必ず開ける
- **AI の判定をサイトの記録にしない。** 質問する道具は読む人のもの。答えは保存しない
- **色相で優劣を作らない。** 線種と濃さで区別する
- **データの限界を隠さない。** ⚠️ 期限超過が3件しか立たない理由も画面に書く

判断の記録は `docs/data-notes/` にある。
- `2026-09-05-region-layer.md` — 地図と国境データ
- `2026-09-05-after-the-money.md` — 金が動いたあとの層、Catalyst Japan から引き継いだ判定基準
